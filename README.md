# Mimtajul Alam Nahin — Portfolio

A responsive portfolio for Mimtajul Alam Nahin, a Computer Science and Engineering student exploring AI, machine learning, and research. Built with Next.js, Tailwind CSS, and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Project structure

- `app/` contains the application shell and page entry point.
- `components/` contains the portfolio sections and navigation.
- `data/content.js` holds profile, contact, skills, research, and project content.
- `public/images/` contains the hero portrait, campus photo, and research banner.
- `public/certificates/` contains the research workshop certificate.

Update portfolio copy and links in `data/content.js`. Place public assets in the matching folder and reference them by their path under `/`.
